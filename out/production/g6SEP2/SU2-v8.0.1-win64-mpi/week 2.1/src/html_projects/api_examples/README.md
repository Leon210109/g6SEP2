# Browser API Examples

This folder contains interactive demonstrations of various browser APIs.

## How to Use
Simply open `index.html` in your browser to see all the working API examples.

## APIs Demonstrated

1. **Geolocation API** - Get user's current location coordinates
2. **Fetch API** - Retrieve data from external APIs (Random User Generator)
3. **LocalStorage API** - Store and retrieve data in the browser
4. **Date API** - HTML5 date picker with date calculations
5. **Canvas API** - Draw shapes and graphics
6. **Notifications API** - Send browser notifications
7. **Clipboard API** - Copy and paste text programmatically
8. **Battery Status API** - Check device battery level
9. **Web Speech API** - Text-to-speech functionality
10. **Intersection Observer API** - Detect when elements enter viewport

## Notes
- Some APIs require user permission (Geolocation, Notifications)
- Battery Status API may not work on all devices
- Clipboard API requires HTTPS or localhost
- All examples are fully functional and interactive

## Files
- `index.html` - Main HTML file with all API sections
- `styles.css` - Styling for the page
- `script.js` - JavaScript code implementing all APIs
